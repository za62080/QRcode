# QR Secure System PWA
## 利用
- `/sender/` スマホ向けQR読取・AES-256-GCM暗号化・ファイル共有
- `/receiver/` スマホ/Windows/Mac向け復号・CSV保存
- メール共有本文へ `/receiver/` の絶対URLを自動挿入
- ReceiverはPCでドラッグ＆ドロップにも対応
- PWA manifest/service workerを同梱。HTTPSで公開すると対応ブラウザでホーム画面/アプリとして追加可能。

## 重要
Webブラウザの制約上、共有先を「メール」に固定して自動送信はしません。OSの共有画面からメールアプリを選択します。
また、メール添付をクリックしただけでWeb復号ページへファイルを自動受け渡しすることは通常できないため、受信者は添付 `.qrenc` を保存し、メール本文の復号URLを開いてファイルを選択します。
暗号化パスワードはメールとは別経路で共有してください。
