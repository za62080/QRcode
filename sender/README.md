# QRコードリーダー 業務向け公開版

## 機能
- QRコード連続読み取り
- CSV / TXT出力
- メール送信画面起動（宛先・件名・本文を事前入力）
- SMS送信画面起動（宛先・本文を事前入力）
- Web Share APIによる共有
- 対応端末ではCSVファイルを実ファイルとして共有に添付
- 社員名・端末名を送信本文とCSVに自動付加
- 社員名、端末名、メール、電話番号、件名を端末内に保存
- 送信後の履歴クリア確認

## 送信完了判定について
Webブラウザは、mailto: / sms: で開いた外部アプリで実際に「送信」されたかを知ることができません。
そのためメール/SMSでは、このWebアプリへ戻った時に「送信操作は完了しましたか？」と確認し、
了承された場合だけ履歴を削除します。

Web Share APIでは共有処理が正常終了した後に履歴クリア確認を表示します。

## CSVのメール添付について
通常のWebページの mailto: 仕様では、任意のローカルファイルをメールへ直接添付できません。
そのため「CSV添付で共有」ボタンでは、対応するiPhone/Androidの共有シートへCSVファイルを渡します。
共有先としてメールアプリを選べば、端末/メールアプリが対応している場合、CSV付きメールとして送れます。
未対応端末では本文共有またはCSVダウンロードへフォールバックします。

## データ
設定値は localStorage に保存されます。QR履歴はページ内メモリのみで、ページを閉じると消えます。
このアプリ自身のサーバーへQRデータや個人設定を送信しません。
